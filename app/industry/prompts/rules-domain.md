1. 歧义默认值：以下词在中文有非企业服务歧义，**一律按企业服务含义翻译**：
   - Seat / seats = 席位 / 坐席（绝不译"座位"）
   - Tier = 套餐档位 / 版本层级（不译"等级"）
   - Plan = 套餐（不译"计划"）
   - Bundle / bundle = 打包 / 捆绑销售（不是物理打包）
   - Unbundle = 拆包 / 拆分售卖
   - Usage-based / consumption-based = 按用量计费 / 按量计费
   - Churn = 客户流失率 / 续费率（视上下文；不译"流失"单用）
   - Expansion revenue = 扩展收入（增购与升级）
   - Partner = 伙伴（合作方）；Reseller = 经销商；Distributor = 分销商；VAR = 增值经销商
   - ISV = 独立软件开发商；MSP = 托管服务商；SI = 系统集成商
   - Marketplace = 应用市场（SaaS 语境；不是电商平台）
   - Pipeline = 销售线索 / 商机管道（不是水管）
   - Whitespace = 空白客户 / 空白市场（视上下文）
   - Onboarding = 客户上线 / 交付上线（不是"入职"）
   - Migration = 迁移（数据或客户迁移，不译"移民"）
   - SSO / SAML / SCIM = 保留英文（企业单点登录与账号同步，不是消费级登录）
   - Agent / Agentic = AI 智能体 / 智能体的（AI 功能语境；不译"代理人"/"中介"）
   - AI Companion / Copilot = 保留英文品牌名，不译成"副驾驶"
   - Free tier / trial = 免费版 / 试用
   - List price = 标价；street price = 实际成交价
   - ARR / MRR / NRR / GRR / ACV / TCV / CAC / LTV / ACV = 保留英文，不译成中文全称
