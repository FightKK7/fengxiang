
【中文措辞规则 — 写具体的人和事，不写套话】

1. 直接写谁做了什么、结果如何、还差什么。不宣告写法（“先给结论”“简单总结”“下面分三点”），不写编稿说明（“便于领导了解”“为后续工作奠定基础”）。
2. 删掉没有事实增量的修饰：圆满、顺利、高效、持续赋能、保驾护航、意义重大、注入新动能、夯实基础、提质增效、降本增效、全方位、一站式、重磅、颠覆、革命性。删完句子没少信息，就说明原句本来没有信息。
3. 抽象词必须落到具体对象和动作：赋能 → 给谁开放了什么能力；抓手 → 具体做法；拉通 / 打通 / 对齐 → 统一了哪些规则、参数或流程；沉淀 → 留下了什么可复用的东西；底座 / 生态 / 矩阵 / 颗粒度 → 写清是什么、覆盖哪些环节；闭环 → 写清完成了哪些环节；工具链 → 具体是哪几件工具。API、CLI、Agent、验重、权限审计、工作流、SLA 这类确有所指的词照常使用。
4. 不用机械句式：不预设读者没想到的反面再纠正（“不是 A，而是 B”只在确有方案比较时用）；不凑三连排比；不用“不仅……更是……”“本质上”“真正的……是……”拔高；段末不复述总结，不用“综上所述”“由此可见”“这说明”“值得注意的是”。
5. 不写无关赞美、感谢、模拟共情、表决心、行业意义；不用宏大背景开头；不评论自己写得好不好。
6. 只改语言，不改事实：数字、状态、人名、公司名、时间与限定条件照原文；“测试通过”不写成“已上线”，“暂未复现”不写成“已修复”，“正在洽谈”不写成“已签约”；不补原文没有的数字、动机或情绪。
7. 不为“像人”写残句、错字或刻意口语；通顺、克制的书面中文即可。

例：×“通过持续赋能，进一步夯实了生态底座” → ○“开放三类 API，第三方应用可以直接读写工单”
例：×“综上所述，本次调整意义重大” → 直接写调整对象、生效时间和读者要核对的条款，不写总结句
