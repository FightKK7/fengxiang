# 行业包

> 状态：当前有效 · 最后核对：2026-10-23

这个行业的知识都在这里：分类、主题、信源、精选标准和门槛。换一个行业，主要就是改这个文件夹和 [`site/`](../site/)（站名、文案、品牌和页面），步骤见 [把它改成你的行业](../docs/customize.md)。

本站已按 2026-10-22 定位定制（给全球企业服务从业者的 AI 时代资讯平台，只收官方一手内容源）；仓库说明见 [`../../README.md`](../../README.md)，信源配置见 [`../docs/sources.md`](../docs/sources.md)。

| 文件 | 内容 |
|---|---|
| `taxonomy.ts` | 分类、标签、公司与机构、防止模型写错公司的词表，这个行业最受关注的那类发布（`RELEASE`） |
| `check-entities.ts` | 身份词典自检：25 家公司的 id / 显示名 / 别名必须唯一解析回自己，代表源优先级符合预期（`node industry/check-entities.ts`） |
| `topics.json` | 主题目录（`/topics`），站点启动时读取 |
| `sources.json` | 首次启动时导入的示范内容源：当前 10 个官方一手 news/blog；roadmap / changelog / 日志等变更监控不进示范（见信源政策） |
| `prompts/` | 每一步的提示词：预筛、评分、写作、结构化、归组、事件综述、周报月报、翻译 |
| `selection.ts` | 入选门槛（当前 T1 65 / T1_5 66 / T2 68，`understandFloor 55`） |
| `gold.example.jsonl` | 精选评测样本的格式示例 |
| `relation-gold.example.jsonl` | 事件关系评测样本的格式示例 |
| `story-digest-eval.example.jsonl` | 事件综述评测案例的格式示例 |
