风向 · 字体许可与来源（OFL.txt）
================================

本目录下的 woff2 是两份开源字体的子集，均按 SIL Open Font License 1.1 发布。
子集化只裁剪字形、未改动字形轮廓；字体名称保留原样（未使用保留字体名做新字体）。

1) FX Serif（fx-serif-600.woff2 / fx-serif-700.woff2）
   来源：Noto Serif SC — https://github.com/notofonts/noto-cjk
   上游文件：https://raw.githubusercontent.com/google/fonts/main/ofl/notoserifsc/NotoSerifSC%5Bwght%5D.ttf
   变体实例：wght 600（标题）/ wght 700（仅报头「风向」与榜单序号）
   版权：Copyright 2012 Google Inc. All Rights Reserved.
   许可：SIL Open Font License 1.1

2) FX Number（fx-number-400.woff2 / fx-number-600.woff2）
   来源：Inter — https://github.com/rsms/inter
   上游文件：https://raw.githubusercontent.com/google/fonts/main/ofl/inter/Inter%5Bopsz,wght%5D.ttf
   变体实例：wght 400 / wght 600，opsz 14（只含数字与数字标点，保留 tnum 特性）
   版权：Copyright 2020 The Inter Project Authors (https://github.com/rsms/inter)
   许可：SIL Open Font License 1.1

子集由 app/scripts/fonts/build-fonts.mjs（fonttools + pyftsubset）生成；
重建命令与体积见 docs/fonts.md。
