它能做什么

从配置好的信源采集内容，生成中文标题和摘要，按时间汇总展示，并每天编成一期「每日精选」。

01

官方信源

仓库预置了 OpenAI、Google Workspace、Salesforce、Slack 等官方信源；每条动态保留来源与原文链接，便于核对。

02

中文摘要与原文对照

条目页先展示中文标题、摘要和出处；正文可用时支持站内阅读，已生成译文的文章支持原文与中文逐段对照。

03

每日精选

默认每天 08:00（北京时间）出刊，从此前 24 小时的动态中选取少量条目，按栏目编排；当期没有符合标准的内容时会明确说明。

04

订阅与 Agent 接入

网页、RSS、公开 API 和 MCP 共用同一套发布数据；公开读取无需注册或 API Key，MCP 提供 7 个工具。

你可以直接部署当前版本，也可以更换信源、分类、提示词和品牌，搭建面向其他行业的资讯站。
